# Spotter

dApp on GenLayer Studionet (61999).

Post a question. A hunter locks a live URL. Validators fetch the page and
close HIT, MISS, or DEAD. The new job id is the open_job transaction return.
last_job_of is only a fallback. Fetch receipts store sha256 / fetch_ok / fail_kind.
